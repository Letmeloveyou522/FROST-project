File size (GB) must be larger than your laptop's RAM, or the OS page cache will hide the SSD signal. (e.g. 8GB RAM → use 10+, 16GB RAM → use 20+)

Auto collection

Runs N trials with the label/session/size/duration above, following the FROST paper: before each trial the OS page cache is reset and the system settles for the buffer time. Recording then starts, the link opens as a new tab in this browser at a fixed time (paper: 10 s trace, open at 2 s), and the tab closes when recording ends. Leave the link empty to collect idle traces. This page must be open in the browser started by python server.py --launch-browser.
