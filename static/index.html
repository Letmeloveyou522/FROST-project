Auto collection

Runs N trials with the label/session/size/duration above, following the FROST paper: before each trial the OS page cache is reset and the system settles for the buffer time. Recording then starts, the link opens as a new tab in this browser at a fixed time (paper: 10 s trace, open at 2 s), and the tab closes when recording ends. Leave the link empty to collect idle traces. This page must be open in the browser started by python server.py --launch-browser.

Long recording with visit log

Records one trace until you press Stop (uses the session/size above). The server logs the exact moment each page starts loading, plus every tab opened or closed, and saves them with the trace, so the notebook can check the model's detected visits.

Browse by hand (box below unticked): once the status says RECORDING, open sites in new tabs or the address bar of this Chrome window. Leave at least 2 s of quiet before each visit and 10 s between visits, and keep recording 8 s after the last one. Turn off Settings → Performance → Preload pages, or Chrome may start loading a page while you are still typing.

Server opens the sites (box ticked): hands off. The server waits a random quiet time, opens the next site in a new tab like auto mode, closes it again, and repeats until you press Stop. With the cache reset ticked, it also resets the OS page cache before recording and after every visit, then lets the system settle, like auto mode before each trial. These are the same kind of visits the models were trained on.

Either way, this page must be open in the browser started by python server.py --launch-browser.
